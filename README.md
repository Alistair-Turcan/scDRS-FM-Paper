This repository accompanies our scDRS-FM manuscript provides two ways of reproducing the paper's results.

1. full_reproduction/ - this repository contains our jupyter notebooks that output the main result figures.
2. small_reproduction/ - a way of rerunning scDRS-FM on the datasets, each dataset subsampled to 10k cells, only 3 replicates, and omits the scPagwas comparison. This can be reproduced in about one day, although the results will not be identical.
